Cómo es la oposición de Policía Local (Madrid)

Concurso-oposición. La fase de oposición pondera 60 % culturales y 40 % físicas. Cada prueba es eliminatoria.

  1. Pruebas culturales — temario 80+3 e idioma 10+2. Cada parte 0–10, mínimo 5. Ponderación 90/10. Siguen 3,5 aspirantes por plaza. EliminatoriaPuntuable Calcular esta prueba →
  2. Psicotécnicas — inteligencia (80+5, apto/no apto, ratio 1,2) y personalidad (160 ítems, perfil del tribunal). EliminatoriaApto / no apto
  3. Pruebas físicas — 800 m, 60 m, balón medicinal, salto y 25 m de natación. Mínimo 5 en cada una. Media aritmética. EliminatoriaPuntuable Calcular esta prueba →
  4. Reconocimiento médico — apto o no apto, anexo III. EliminatoriaApto / no apto
  5. Concurso — máximo 2 puntos (servicios, titulaciones e idiomas). Solo si superaste la oposición. Baremo
  6. Curso selectivo de formación — 0 a 10, mínimo 5 en cada asignatura. Formación

La calculadora de nota cubre solo las pruebas culturales. El 5 es el suelo de cada parte, no el corte: el recorte es 3,5 aspirantes por plaza.

La fase de oposición, si superas las cuatro pruebas, es 60 % culturales + 40 % físicas. El concurso (máximo 2) se suma después. Aquí no se fabrica esa suma si no has metido las físicas.

El psicotécnico y el médico los califica el tribunal. No hay fórmula pública de aciertos que convierta el test de personalidad en una nota.

Usa la calculadora de nota para el temario y el idioma, y la de físicas para el anexo II. Las listas salen en el Ayuntamiento de Madrid.
